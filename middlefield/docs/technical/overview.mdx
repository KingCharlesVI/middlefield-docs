# Overview

Deeper technical reference for the Middlefield homelab — mainly useful if something breaks and you need to know what's actually running where.

## Service ports

Each service is reachable internally on its own port; a reverse proxy maps the public subdomains (`jellyfin.middlefield.xyz`, `files.middlefield.xyz`, etc.) to these ports so you don't need to know them for day-to-day use. They're listed here for reference.

| Service | Subdomain | Default port |
|---|---|---|
| Jellyfin | `jellyfin.middlefield.xyz` | `8096` (HTTP), `8920` (HTTPS) |
| Gokapi | `files.middlefield.xyz` | `53842` |
| Calibre Content Server | `library.middlefield.xyz` | `8080` |
| Seerr | `requests.middlefield.xyz` | `5055` |
| Uptime Kuma | `status.middlefield.xyz` | `3001` |
| Docs | `docs.middlefield.xyz` | `3000` |
| DNS (http) | `No external URL` | `4000` |
| DNS (https) | `No external URL` | `4001` |
| DNS (TCP/UDP) | `No external URL` | `53` |
| DNS Monitoring | `dnsmonitor.middlefield.xyz` | `4020` |
| Dashboard | `middlefield.xyz` | `8067` |
| Rack Designer | `rack.middlefield.xyz` | `5000` |
