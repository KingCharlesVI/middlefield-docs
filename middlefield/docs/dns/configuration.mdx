# Configuration Reference

Blocky is configured through a single YAML file (`config.yml`), reloaded by restarting the service (some sections, like blocklists, can be refreshed live via the API/Dashboard — see [Blocklists](./blocklists)). This page walks through the sections that matter, roughly in the order Blocky evaluates them.
